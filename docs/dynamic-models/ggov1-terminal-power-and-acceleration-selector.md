# GGOV1 terminal power and acceleration control

GGOV1 and GGOV1D share the electrical-power transducer and fuel selector. The electrical-power transducer reads the round-rotor stator's terminal active-power sample during initialization and at each solver stage. Initialization applies the same machine-to-turbine base conversion to the initial transducer state and the droop and supervisory MW references. During integration, the cached sample supplies the transducer derivative and the algebraic measurement when its lag is bypassed. The stator's swing-equation power remains available to the machine. Reading the terminal sample leaves the stator current and swing input intact. An uninitialized stator and machine types without this terminal sample retain their existing electrical-power accessor.

With zero acceleration-limiter gain, the acceleration path contributes the existing upper selector ceiling. The speed and load paths then determine the fuel-stroke command within the declared travel limits. Treating the preceding selected command as a zero-gain acceleration limit made the command nonincreasing. A temporary reduction could therefore pin both the fuel command and the turbine output below the subsequent requested level. Nonzero acceleration gain continues to use the preceding selector and the acceleration increment. The modified Euler and staggered paths share the selector evaluation.

With zero proportional load-limiter gain, the straight integrator starts at the normalized upper fuel-selector input of 1.0. A zero integral gain then leaves the branch at that ceiling. A nonzero integral gain can move the branch in response to the temperature error. Starting at the initial valve position instead would introduce an unintended valve-opening limit. Nonzero proportional gain still starts the PI integrator at the initial actuator position.

The speed PID integrator tracks the selected fuel-stroke command relative to its own state, with gain Ki/Kp. The selected command can come from the speed, temperature, or acceleration path. Even with the speed path selected, the tracking residual includes its filtered derivative contribution. The PI-error form alone loses that contribution. With zero effective Kp the integrator uses Ki times the limited error directly. With zero Ki its rate is zero. Reference-simulator component replays with unequal gains and a zero-Kp control discriminate the equations.

The regression tests exercise a fuel-command reduction followed by recovery at zero gain, the positive-gain staggered recurrence, and the transducer's response with nonzero stator resistance and unequal machine and turbine bases. Reference play-ins use identical speed and terminal active power on both implementations. The corrected governor matches a separate coupled machine fixture after fault clearing, including recovery above the initial stroke. Large-system trajectories and their source data are retained in private QA.
